# Mr. Drury's Physics Simulations

Interactive, PhET-style physics simulations for Newton South High School classes.

**Live site:** https://drureyr.github.io/physics-sims/

| Course | Unit | Link |
|---|---|---|
| ACP Physics | Energy | https://drureyr.github.io/physics-sims/acp/energy/ |

Each simulation is a self-contained web page (HTML + JavaScript) that runs in any browser, with no login or install.
Shared styles and helpers live in `assets/`.
